# Archived aluminium upper concepts

These four generated SVGs were early coordination concepts for three basket
sizes and a monolithic corner. They are superseded by the user-rendered,
millimetre-scaled cutting files listed in
`docs/packs/c/aluminium-cut-parts.md` and must not be sent for fabrication.

`archive/docs/calcs/generate_r512_uppers.py` is the generator that produced
them and is retained only for design history.
