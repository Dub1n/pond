## Evidence checklist

- Photo set: pads, beams, hangers, straps, bracing, liner clamp, decking fall/gaps.
- Check sheets: set-out, beam alignment, joist spacing, decking fall/gaps.
- Certificates: UC4 treatment, C24 grading, fastener/hardware datasheets.
- Close-out: torque record, snag list, sign-off.

Mark each item as filed before issuing the pack. Use project-specific filenames for traceability (e.g., `C-ITP-hangers-2024-___.jpg`).
